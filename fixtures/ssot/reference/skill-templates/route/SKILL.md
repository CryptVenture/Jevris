# Jevris route — reference template, not an installed plugin

Establish the current task and the user's model/effort pins from trusted session state. Preserve the original objective and mandatory checks. Use the planned `jevris_status` and `jevris_plan_route` tools only when registered by the trusted Jevris host; otherwise report that this capability is not installed. Do not manufacture tool names or execute shell commands to simulate it.

Request a recommendation using approved task metadata and evidence handles. Do not send raw source, secrets or complete transcripts without an applicable data policy. Explain the recommended worker profile, eligibility, uncertainty, estimated total cost and required verification. A Jev choice is not proof that a coding model can complete the task.

This template is advisory. Do not change the main session model, grant permissions, edit settings, launch workers or override an explicit user pin. A supported, owned orchestrator may apply a separately authorized plan and return an action receipt. Report unsupported capabilities and abstentions plainly.
