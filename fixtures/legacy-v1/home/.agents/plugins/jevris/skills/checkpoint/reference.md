# Checkpoint interface

This file is interface text. It is not a skill and it does not grant a tool.

A checkpoint keeps requirements and decisions the trusted host already supplied. It does not mark a check passed. A missing sidecar is an abstention. A missing sidecar is abstention. No check is marked passed. Installed is not enforced.

Read this file only when the checkpoint skill is invoked. Pass --home as its own argument. Do not interpolate user text into a shell. Do not grant a permission.

Each of these commands abstains when the sidecar is absent: status, plan, route, checkpoint, recover, verify, explain, configure, doctor, install, uninstall, credential, policy, gates, kill-switch, shadow, shortlist.
